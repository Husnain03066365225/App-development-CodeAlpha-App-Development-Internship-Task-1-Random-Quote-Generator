# 📜 Random Quote Generator

A simple and elegant **Random Quote Generator** built with **Flutter** as **Task 1** of the **CodeAlpha App Development Internship**.

The application displays a random inspirational quote along with its author whenever the user taps the **"New Quote"** button. It is designed with a clean and minimal user interface to provide a smooth user experience.

---

## ✨ Features

- 🎯 Display a random quote
- 🔄 Generate a new quote with one click
- ✍️ Shows both quote and author
- 📱 Clean and responsive UI
- ⚡ Fast and lightweight Flutter application

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Husnain03066365225/App-development-CodeAlpha-App-Development-Internship-Task-1-Random-Quote-Generator.git
```

### Navigate to project

```bash
cd CodeAlpha_RandomQuoteGenerator
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
